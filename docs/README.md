# Documentación del Laboratorio

## Introducción

Este laboratorio tiene como finalidad implementar un entorno de pruebas de seguridad web utilizando aplicaciones vulnerables y la herramienta OWASP ZAP para identificar vulnerabilidades pertenecientes al estándar OWASP Top 10.

El proyecto se desarrolla de forma colaborativa mediante GitHub, donde cada integrante cumple una función específica dentro de un flujo de trabajo secuencial.

---

## Objetivos

### Objetivo General

Implementar un laboratorio práctico para la detección de vulnerabilidades web mediante OWASP ZAP utilizando aplicaciones vulnerables y un entorno colaborativo basado en GitHub.

### Objetivos Específicos

* Configurar un entorno de pruebas seguro.
* Implementar aplicaciones web vulnerables.
* Utilizar OWASP ZAP para actividades de reconocimiento y análisis.
* Detectar vulnerabilidades asociadas al OWASP Top 10.
* Documentar hallazgos y evidencias.
* Elaborar un informe técnico final.

## Metodología

El laboratorio se desarrollará en cuatro fases:

### Fase 1: Preparación del Entorno

* Configuración de GitHub.
* Instalación de Docker Desktop.
* Configuración de WSL2.
* Implementación de DVWA.
* Implementación de OWASP Juice Shop.
* Implementación de WebGoat.

### Fase 2: Reconocimiento

* Configuración de OWASP ZAP.
* Spider Scan.
* Ajax Spider.
* Passive Scan.

### Fase 3: Detección de Vulnerabilidades

* Active Scan.
* Identificación de vulnerabilidades.
* Generación de reportes.

### Fase 4: Análisis y Reporte

* Consolidación de resultados.
* Clasificación de hallazgos.
* Elaboración del informe final.
